# Portafolio Web Personal - Isaac Canales

Proyecto de desarrollo web desarrollado con HTML5 semántico y CSS3 puro, estructurado bajo un sistema de control de versiones con Git.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Maquetación con Flexbox, CSS Grid y variables de color.
- **Git:** Control de versiones con 6 commits principales.
